Data and Model

EEE213 - Machine Learning Project

Dataset

The project uses the Combined Cycle Power Plant dataset.

  • Ambient Temperature (AT)
  • Exhaust Vacuum (V)
  • Ambient Pressure (AP)
  • Relative Humidity (RH)
  • Electrical Power Output (PE)

Machine Learning

Baseline and linear regression models are evaluated.

Results

  • Baseline MAE: 14.723 MW
  • AT Regression MAE: 4.333 MW
  • V Regression MAE: 6.488 MW
